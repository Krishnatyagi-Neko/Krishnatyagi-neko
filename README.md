> Systems &gt; content, always. Rebuild the mechanic from scratch before reaching for the asset store.

**Active build — Leviathan (game jam)**
A vertical 2D parkour game: dodge hazards climbing upward while a leviathan closes in from below. Side rooms hold minigames that recruit support characters to help take it down. Player controller built from scratch on the new Input System — coyote time, jump buffering, variable jump height, all hand-rolled to actually learn the feel instead of dropping in a package.
