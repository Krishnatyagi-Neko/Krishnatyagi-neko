## About

Computer Science student specializing in Data Science, spending most of that
time inside Unity anyway. I build systems before I build levels — movement,
state, and player feedback first, polish after. Documenting the process on
GitHub and LinkedIn on the way to a first internship and, eventually, a game
worth shipping.
